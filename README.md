# PEHLI SEEDHI

### Your experience. Your next step.

> An AI-powered career navigation platform that helps early-career women turn existing experience into transferable skills, career direction, demonstrable proof, and practical employment action.

---
## Overview

Many women do not lack effort, learning, or experience.

The challenge is often translating what they have already done into a clear career direction and a credible path toward employment.

PEHLI SEEDHI was built around one core idea:

**Your existing experience already contains valuable skills. The first step is learning how to identify, prove, and use them.**

Instead of starting with another list of courses, PEHLI SEEDHI starts with the user's own experience.

It helps answer:

- What skills do I already have?
- Where can those skills be useful?
- What am I missing for my next role?
- What evidence can I build?
- Am I ready to take the next step?
- Can I evaluate an opportunity before trusting it?
- Who can I realistically reach out to?
- What should I do today?

---

# The Problem

Completing a course does not automatically answer:

1. **What roles fit my existing skills?**
2. **Am I actually ready to apply?**
3. **How do I evaluate whether an opportunity is credible?**

Traditional job platforms generally begin with available vacancies.

PEHLI SEEDHI begins with the person.

It first understands the user's experience, extracts transferable skills, identifies gaps, and builds evidence before moving toward employment action.

---

# The Solution

PEHLI SEEDHI follows an evidence-based career journey:

**Experience → Skills → Career Direction → Gaps → Proof → Readiness → Opportunity Check → Outreach → Action**

The platform combines AI-powered interpretation with explicit evidence and safety guardrails.

It does not promise employment.

Instead, it helps the user make more informed and defensible career decisions.

# User Journey

## 1. DISCOVER

### MY EXPERIENCE

The user describes their experience in their own words.

This can include:

- Education
- Projects
- Volunteering
- Responsibilities
- Problems solved
- Practical work
- Existing skills
- Career goals

The platform uses this information as the foundation for the rest of the journey.

### MY TRANSFERABLE SKILLS

AI extracts **5 to 7 evidence-backed transferable skills** from the user's actual experience.

Each skill includes:

- Skill name
- Where it was demonstrated
- Why it matters
- Where it can be useful
- Confidence level

Skill names are kept in English and are only generated when supported by the user's evidence.

### MY SKILL MAP

The platform connects:

**Current Experience → Transferable Skill → Career Relevance**

It then identifies:

- Skills the user can build on
- Skills that need strengthening

---

# 2. BUILD

## MY NEXT STEP

The platform identifies realistic next-role directions based on:

- Existing experience
- Transferable skills
- Career direction
- Skills that need strengthening

It explains why each direction fits and what would make the user more ready.

## MY SKILL GAPS

Instead of generating a long list of weaknesses, PEHLI SEEDHI prioritizes the **three most important skill gaps** for the user's next role.

Each gap includes:

- Why it matters
- What the user already knows
- What they still need to demonstrate
- Priority

## MY PROOF

PEHLI SEEDHI converts a skill gap into a practical **7 to 14 day proof challenge**.

The goal is to move from:

> "I have this skill."

to:

> "I can demonstrate this skill."

The output includes a tangible deliverable that can later be discussed in an interview or included in a portfolio.

## MY 90-DAY PLAN

The platform converts the user's career direction into a realistic 90-day roadmap.

The plan adapts to:

- Available time per day
- Job-search urgency
- Current skill gaps
- Proof requirements

The system is explicitly instructed not to exceed the user's available time.

## RECOVERY PLAN

Plans change.

Users can indicate that:

- They are on track
- They missed one week
- They missed more than one week
- Their available time changed
- Their career goal changed

The plan then adapts without unnecessarily restarting completed work.

# 3. EMPLOYMENT NAVIGATOR

The original PEHLI SEEDHI solution already included an Employer Ready section.

The Grand Finale plot twist shifted the challenge from simply helping a learner understand what to learn next toward helping her navigate the path toward employment.

Instead of rebuilding the solution, PEHLI SEEDHI extends that existing foundation into an **Employment Navigator**.

The new layer answers five practical questions:

**Am I ready?  
Can I trust this opportunity?  
Who can I reach?  
What can I show?  
What should I do next?**

---

## MY READINESS

PEHLI SEEDHI separates **confidence from evidence**.

The user can provide a self-reported readiness score, but that score is never treated as proof of job readiness.

The AI compares:

**Self-Perception vs Evidence**

The evidence-based assessment considers:

- Transferable skills
- Skill gaps
- Career alignment
- Proof
- Current experience

Possible readiness states include:

- READY TO TAKE THE NEXT STEP
- ALMOST READY
- BUILD MORE EVIDENCE
- NEEDS MORE DEVELOPMENT

This prevents confidence alone from being treated as evidence.

---

## VERIFY OPPORTUNITY

Users can paste:

- A job description
- Recruiter message
- Offer text
- Opportunity advertisement

The platform checks the supplied text for risk signals such as:

- Upfront payment or registration fees
- Requests for money
- Suspicious personal information requests
- Vague company identity
- Unrealistic compensation
- Mass recruitment language
- Pressure tactics
- Guaranteed selection
- Unclear application process
- Suspicious contact details

It also checks the opportunity against the user's demonstrated skills.

### Output

**Credibility Signal**

- Low Concern
- Some Concerns
- High Concern
- Insufficient Information

It also provides:

- Specific red flags from the supplied text
- Role match
- Matching evidence
- Most important gap
- Exactly 3 verification steps

### Important Safety Principle

PEHLI SEEDHI does **not** claim that a job is definitely genuine.

A lack of obvious red flags is not treated as proof of legitimacy.

The goal is to help the user make a safer, more informed decision.

---

## DIRECT OUTREACH

Not every woman starts with a professional network.

PEHLI SEEDHI helps identify realistic connection pathways without inventing recruiters, alumni, companies, or contacts.

It suggests channel types such as:

- Alumni communities
- LinkedIn communities
- Professional associations
- Industry events
- Peer communities

It also generates context-aware outreach drafts for:

- LinkedIn
- Cold email
- Informational interviews
- Referral conversations

The user's outreach confidence controls how direct the suggested action should be.

---

## PORTFOLIO ARTIFACT

PEHLI SEEDHI turns the user's proof work into a portfolio-ready structure.

Depending on the target role, it can generate a structure for:

- GitHub README
- Case Study
- PRD
- Project Showcase

The artifact is built only from the user's supplied evidence.

If information is missing, the system uses:

`[Add your evidence here]`

It does not invent:

- Metrics
- Results
- Employers
- Users
- Achievements
- Certifications
- Outcomes

The user adds their own real portfolio link when the work is hosted.

---

## DAILY SPRINT

A 90-day plan can still feel overwhelming.

DAILY SPRINT converts the strategy into a practical 7-day action plan.

Every day contains:

- 15-minute action
- Expected output
- Why it matters

The most immediate section is:

### YOUR NEXT 15 MINUTES

This identifies the highest-impact action the user can realistically complete now.

The sprint adapts to:

- Available time
- Job-search urgency
- Outreach confidence
- Evidence-based readiness
- Current progress

---

## EMPLOYMENT SNAPSHOT

The final layer provides a compact career status view.

It summarizes:

- Target role
- Current status
- Top 3 skills
- Evidence-based readiness
- Biggest skill gap
- Proof status
- Opportunity signal
- Best connection channel
- Next move

Information is explicitly labelled as:

- **KNOWN**
- **INFERRED**
- **NOT YET ASSESSED**

This makes the system more transparent about what it knows and what it does not know.

# Key Innovation

## Evidence-Based Skill Extraction

The core innovation of PEHLI SEEDHI is not simply recommending careers.

It is helping users recognize transferable skills that are already present in their experience.

For example:

A user may describe:

> Coordinated registrations, communicated with participants, maintained spreadsheets, and helped a team meet deadlines.

Instead of asking the user to select generic skills, PEHLI SEEDHI can identify evidence-backed capabilities such as:

- Coordination
- Communication
- Data Organization
- Problem Solving

The important part is the connection:

**Experience → Evidence → Skill → Career Relevance**

# Personalization Inputs

PEHLI SEEDHI also uses user-controlled inputs to adapt the experience.

### Time Available Per Day

Controls the amount of work suggested.

The system is instructed never to exceed the user's available time.

### Job Search Urgency

Moves the user through:

**Learn → Proof → Reach → Check → Apply**

This changes the emphasis of the recommended actions.

### Confidence to Reach Out

Controls how direct the suggested networking action should be.

Lower confidence results in lower-pressure preparation steps.

### Readiness Self Check

Captures how ready the user feels.

It is explicitly treated as **self-perception, not evidence**.

# Guardrails

PEHLI SEEDHI is designed with explicit AI guardrails.

The system should not:

- Invent work experience
- Invent employers
- Invent recruiters
- Invent alumni
- Invent job vacancies
- Invent salaries
- Invent metrics
- Invent achievements
- Guarantee employment
- Claim an opportunity is definitely genuine
- Treat confidence as proof
- Generate live portfolio URLs
- Exceed the user's available time

When information is insufficient, the system is instructed to say so.

This makes transparency part of the product design.

# Testing Strategy

PEHLI SEEDHI was designed to be tested across different levels of information quality.

## Normal Case

The user provides:

- Clear experience
- Target role
- Existing skills
- Career context
- Opportunity information

The system should produce a connected journey from skills to employment actions.

## Edge Case

The user has constraints such as:

- Career gap
- Limited recent experience
- Low outreach confidence
- Limited time

The system should adapt instead of treating the user as a blank slate.

## Failure Case

The user provides very little usable information.

The system should not invent missing information.

Instead, it should return an appropriate insufficient-information response.

### Testing Principle

> A normal case tests whether the solution works when the expected information is available. An edge case tests whether the solution can adapt to real-world constraints. A failure case tests whether the AI knows when it does not have enough evidence to answer.

# What PEHLI SEEDHI Does Not Do

PEHLI SEEDHI does not:

- Guarantee employment
- Claim to authenticate employers automatically

- Invent professional contacts
- Decide a user's career for them

It provides structured evidence and practical next steps so the user can make better-informed decisions.
