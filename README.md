PEHLI SEEDHI:
Your experience. Your next step.

PEHLI SEEDHI is an AI-powered career navigation platform built with Amazon PartyRock and Amazon Bedrock.

It helps women identify transferable skills from their existing experience, map those skills to career directions, identify gaps, build proof, assess readiness, evaluate opportunities, and take practical employment actions.

User Journey

1. Discover
Experience → Transferable Skills → Skill Map

2. Build
Skill Gaps → Next Step → Proof → 90-Day Plan → Recovery

3. Navigate Employment
Readiness → Opportunity Verification → Outreach → Portfolio → Daily Sprint → Employment Snapshot

Tech Stack

Amazon PartyRock: Application and workflow

Amazon Bedrock: Foundation model infrastructure

Claude Sonnet 4.6: AI reasoning across the core widgets

Prompt Engineering: Evidence-based, anti-hallucination instructions



Key Innovation

1)Evidence-based skill extraction

Instead of asking users to select generic skills, PEHLI SEEDHI extracts transferable skills from what they have actually done and connects those skills to career progression.

2)Employment Navigator

The second layer extends the original career-planning journey into employment navigation:

MY READINESS: Evidence-based readiness assessment

VERIFY OPPORTUNITY: Risk signals + role match + verification steps

DIRECT OUTREACH: Practical connection pathways and message drafts

PORTFOLIO ARTIFACT: Converts experience into demonstrable proof

DAILY SPRINT: Converts the plan into immediate actions

EMPLOYMENT SNAPSHOT: Compact career status summary
